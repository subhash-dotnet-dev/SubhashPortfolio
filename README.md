**# Subhash Yadav — .NET Full Stack Developer Portfolio**



**A production-grade personal portfolio built with \*\*ASP.NET Core Web API\*\* + \*\*React.js\*\* + \*\*SQL Server\*\*, following Clean Architecture and industry best practices.**



**## 🧱 Architecture**



**- \*\*Backend\*\*: ASP.NET Core Web API (Clean Architecture — API / Application / Domain / Infrastructure)**

**- \*\*Frontend\*\*: React.js + Vite**

**- \*\*Database\*\*: Microsoft SQL Server (EF Core Code-First)**

**- \*\*Auth\*\*: JWT + Role-Based Authorization**

**- \*\*Deployment\*\*: Backend → MonsterASP / SmarterASP | Frontend → Vercel / Netlify**
